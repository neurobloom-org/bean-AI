# Bean AI Core
## Status: 🚧 Active Development

The central intelligence repository for Bean – the empathetic mental wellness companion. This repo currently houses our core machine learning models for emotion classification and therapeutic dialogue.

## Current Features

1. SML Classification Model (Emotion Detection)
Purpose: Analyzing user text/audio input to classify emotional states (e.g., Anxious, Neutral, Distressed).

Tech: Python

Status: ✅ Operational

2. Therapeutic Companion AI
Purpose: The conversational engine that generates supportive, "co-regulating" responses.

Tech: OpenAI API (Fine-tuned System Prompt for empathy).

Capabilities: Active listening, crisis keyword detection, and grounding techniques.

Status: ✅ Operational
